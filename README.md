# Петръ Отель — вариант 2

Презентационный сайт с акварельным первым экраном, русской и английской версиями, 15 категориями номеров и галереей из 125 фотографий.

Демо: https://weks666.github.io/petr-hotel-2/

## Локальный запуск

Нужен Node.js 20 или новее. Внешних зависимостей нет.

```powershell
npm run build
npm start
```

Локальный адрес: http://127.0.0.1:4178/

## GitHub Pages

Push в main запускает сборку, проверки и публикацию из папки dist. Workflow: .github/workflows/pages.yml.

Аналогичная сборка для GitHub Pages в PowerShell:

```powershell
$env:BASE_PATH='/petr-hotel-2'
$env:PUBLIC_DEMO='1'
npm run build
npm run check
npm run check:dates
```

BASE_PATH задаёт префикс адреса проекта. PUBLIC_DEMO добавляет подпись студии в опубликованное демо. Без этих переменных сборка работает в корне локального сервера.

## Страницы и функции

- Главная: акварельная сцена, сравнение номеров, карта, услуги, отзывы и контакты.
- /rooms/: каталог 15 категорий с фильтрами и отдельными страницами.
- /gallery/: 125 фотографий с фильтрами и просмотром на весь экран.
- /en/: английские версии всех гостевых страниц.
- Календарь, гости, возраст детей и промокод передаются в TravelLine Booking Engine.

Бронирование и личный кабинет обслуживает TravelLine по существующему адресу модуля отеля. Демо самостоятельно не создаёт бронирования и не принимает оплату. Карта использует внешний сервис Яндекса.

Фотографии отеля используются для презентации редизайна; их публикация здесь не предоставляет прав на дальнейшее использование.

## Цены и заявки

В src/data/rates.json сохранены минимальные суммы за две ночи, 6–8 октября 2026, 1 взрослый, без детей; проверено 29 сентября в TravelLine. Семь категорий с ценой, пять распроданы на эти даты, три не представлены. Это датированный снимок, а не онлайн-остатки.

Формы трансфера, визовой поддержки и консьержа проверяют поля и показывают подготовленную заявку только в браузере. Отправка не подключена. Публичные формы не собирают паспортные данные или пароли.

Панели используют dialog и явное hidden; зависимости от Popover API нет. Кнопка и горячая клавиша повтора акварели удалены.
